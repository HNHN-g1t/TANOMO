# シリーズ「いただきますの裏側」

作成日：2026-10-30

**一言で：** 「いただきます」で始まり、少し怖くてイヤな、でもなぜか目が離せない「命が食べ物になるまで」を図解で見せ、もう一度「いただきます」で終わる60秒。

同じ「いただきます」が、見終わったあとには重く聞こえる。それがこのシリーズのオチ。

---

## 固定の型（毎回同じ）

| 時間 | 中身 | 演出 |
|---|---|---|
| 0〜5秒 | **入口のいただきます。** 食卓で手を合わせる。ナレ「『いただきます』は、『命をいただきます』という意味だとも言われています」 | 明るい食卓、生活音。いつもの風景 |
| 5〜8秒 | **今日の命。** 黒い画面に動物の線画と、名前・年齢・体重だけ | 音が消える。ここで空気を変える |
| 8〜45秒 | **裏側。** 工程を図解で1ステップずつ。番号と時刻を出す | 黒地に白い線画。色は使わない。音は金属音・水音・機械音だけ |
| 45〜53秒 | **数字。** 1つの命が、何食分になったか | 数字が積み上がる |
| 53〜60秒 | **出口のいただきます。** 冒頭と同じ食卓、同じ手、同じ言葉 | 生活音が戻る。冒頭とまったく同じ画角で撮る |

---

## 「少し怖い」の作り方（見せずに怖がらせる）

血や切断面は**一切描かない**。怖さは次の4つだけで作る。

1. **音を抜く。** 食卓の生活音から、急に無音にする
2. **線画と黒。** 写実にしない。白い線だけで描く。リアルにしないほど想像が働く
3. **赤は1回だけ。** 放血の工程で、画面全体が一瞬だけ赤くなる。形は描かない
4. **淡々と数える。** ナレーションは感情を入れず、工程番号と時刻を読み上げるだけ

---

## 守ること

- **実写の解体・血は使わない。** プラットフォームの年齢制限・規約違反を避ける。線画の図解に限る
- **言葉は「と畜」。** 法律（と畜場法）や現場で使われる表記に合わせる。タイトル・テロップに「屠殺」は使わない
- **働く人への敬意。** この仕事は歴史的に差別を受けてきた。「残酷な仕事」として描かない。ナレーションは「〜してくれている」ではなく事実を淡々と述べ、最後の数字と「いただきます」で敬意を伝える
- **動物を擬人化しない。** 泣く、しゃべるなどの演出はしない。かわいそうで終わらせると「見なきゃよかった」になる
- **工程と数字は監修を取る。** と畜場・食肉衛生検査所・畜産の専門家のいずれかに確認する
