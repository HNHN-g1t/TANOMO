# 打ち合わせ：ショート動画シリーズ「日本人の美意識」

作成日：2026-10-30

日本人の特性（恥の文化、カイゼン、空気を読む…）を、**笑って見始めて、最後に少しホロリとする** 60秒のシリーズにする。

---

## 前提（違っていれば直す）

| 項目 | 仮置き |
|---|---|
| 視聴者 | 20〜40代の日本人。「あるある」で笑えて、自分の国を少し好きになれる層 |
| 媒体 | YouTubeショート / TikTok / Reels（縦型・60秒以内） |
| 制作 | 少人数・低予算。実写コント or ナレーション＋素材 or AI映像 |
| 頻度 | 週2〜3本 |

---

## シリーズの型

**仮タイトル案**
1. 「ニッポンの美意識、ちょっとヘン。」 ← 推奨（笑いとホロリの両方に効く）
2. 「なぜ日本人は〇〇するのか」
3. 「恥ずかしながら、日本人です。」

**60秒の固定構成**

| 時間 | 中身 | ねらい |
|---|---|---|
| 0〜3秒 | あるある場面を一発で見せる（例：謝りながらドアを開ける） | スワイプされない |
| 3〜35秒 | 誇張コント or 「海外から見るとこう」 | 笑い |
| 35〜50秒 | 起源・理由を1つだけ明かす（歴史・言葉の由来・実話） | 「へぇ」 |
| 50〜60秒 | 決め台詞で反転。「ヘンだけど、悪くない。」 | ホロリ・保存・シェア |

**回の比率：** 笑い回 3 ： ホロリ回 1。毎回ラストの一言だけは温かく終える。

---

## 方向性3案

### ① トレンド乗り型：「外から見たニッポン」
- 外国人目線のPOV・リアクション形式。いま強い「日本すごい／日本ヘン」フォーマットに乗る
- 例：「日本の電車が20秒早く出発して謝罪した話」
- 弱み：競合が多い。差は「最後のホロリ」でつける

### ② 差別化型：「美意識の正体」
- 行動のルーツを1本1つ掘る。恥＝世間の目、もったいない＝付喪神、など
- 例：「なぜ日本人は割れた器を金で直すのか（金継ぎ）」
- 強み：保存されやすく、シリーズの格が上がる

### ③ 実験型：「擬人化ニッポン」
- 「恥」「空気」「カイゼン」をキャラクターにしてコントにする（AI映像やイラストと相性がいい）
- 例：カイゼン君が恋人に「改善点が3つあります」と言ってフラれる
- 強み：キャラが定着すればシリーズの顔になる

> **推奨：②を軸に、①のフックと③のキャラを混ぜる。** 冒頭は外から見た違和感（①）、中盤で正体を明かす（②）。人気が出たテーマはキャラ化（③）。
